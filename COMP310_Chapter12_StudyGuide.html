Social Choice Theory, Voting Procedures & Impossibility Theorems

1. Social Choice Theory

We continue in the same multi-agent framework as Chapter 11: agents interact in game-like encounters and act strategically.

Core Idea
Social choice theory is concerned with group decision making. Agents make decisions based on their own preferences, but they are aware of other agents' preferences too. The classic example is voting — formally, the issue is combining preferences to derive a social outcome.
Exam Insight
The key tension: different voters have different preference orders. How do we combine them into one group decision that reflects everyone's views "as closely as possible"? As we'll see, no perfect method exists.

2. Components of a Social Choice Model

Formal Setup
  • Ag = {1, ..., n} — a set of voters (agents who express preferences)
  • Ω = {ω1, ω2, ...} — a set of outcomes (think of these as candidates)
  • If |Ω| = 2, we have a pairwise election
  • Each voter has a preference ordering over Ω
Preference Order Example
Suppose Ω = {pear, plum, banana, orange}
Agent i's preference order: (banana, plum, pear, orange)
Meaning: banana ≻i plum ≻i pear ≻i orange
The ≻i symbol means "agent i strictly prefers"
Key Question
Given a collection of preference orders (one per voter), how do we combine them to derive a group decision that reflects everyone's preferences as closely as possible?

3. Social Welfare Function vs Social Choice Function

Social Welfare Function (SWF)
f : Π(Ω) × ... × Π(Ω) → Π(Ω)

Takes n preference orders as input and produces a social preference order (a complete ranking).

ω ≻* ω' means ω is ranked above ω' in the social ordering.

Example: combining search engine results, collaborative filtering

Social Choice Function (SCF)
f : Π(Ω) × ... × Π(Ω) → Ω

Takes n preference orders as input and produces a single winner (just one outcome, not a ranking).

If you have an SWF, you automatically have an SCF (just take the top-ranked outcome).

Example: agents choosing a joint plan

Terminology
For the rest of this chapter, both SWFs and SCFs are referred to as voting procedures.

4. Plurality Voting

How It Works
  • This is a social choice function (selects one winner)
  • Each voter submits their preference order
  • Each candidate gets one point for every preference order that ranks them first
  • Winner = candidate with the most first-place votes
  • Also known as first past the post or relative majority
  • With only 2 candidates, plurality = simple majority election
Anomaly with Plurality

|Ag| = 100 voters, Ω = {ω1, ω2, ω3}

CandidateFirst-Place Votes
ω140%
ω230%
ω330%

ω1 wins even though a clear majority (60%) prefer another candidate!

Plurality completely ignores 2nd, 3rd, 4th choices — it only counts who's ranked first.

5. Strategic Manipulation by Tactical Voting

The Problem

Suppose agent i has preferences: ω1 ≻i ω2 ≻i ω3

But agent i believes:

  • 49% of voters prefer: ω2 ≻ ω1 ≻ ω3
  • 49% of voters prefer: ω3 ≻ ω2 ≻ ω1

Agent i may do better voting for ω2 (their second choice) instead of ω1, to prevent ω3 from winning.

This is tactical voting — an example of strategic manipulation.

Why It Matters
Voters can benefit by lying about their true preferences. This undermines the entire point of voting — getting an honest reflection of group opinion.

6. Condorcet's Paradox

The Paradox (Slide 12-13)

In collective decision-making, it seems like majority voting should produce a satisfactory outcome. But...

Suppose Ag = {1, 2, 3} and Ω = {ω1, ω2, ω3} with:

ω1 ≻1 ω2 ≻1 ω3
ω3 ≻2 ω1 ≻2 ω2
ω2 ≻3 ω3 ≻3 ω1
The Cycle
  • If we pick ω1, 2/3 voters prefer ω3 to ω1
  • If we pick ω2, 2/3 voters prefer ω1 to ω2
  • If we pick ω3, 2/3 voters prefer ω2 to ω3

No matter which outcome we choose, a majority of voters will be unhappy.

Preferences form a cycle: ω1 beats ω2, ω2 beats ω3, ω3 beats ω1.

7. Sequential Majority Elections

One way to improve on plurality: reduce a general voting scenario to a series of pairwise elections.

Linear Sequential Pairwise Elections

How It Works

Pick an ordering of outcomes called the agenda (e.g., ω2, ω3, ω4, ω1)

1
First election: ω2 vs ω3
2
Winner faces ω4
3
Winner of that faces ω1

Can also organise as a balanced binary tree (like a tournament bracket / Final Four).

Critical Flaw — Agenda Dependence

The final outcome may depend not just on voter preferences, but also on the election agenda!

With 33-33-33 voter split and cyclic preferences, every candidate can be made to win by choosing the right agenda:

AgendaWinner
(ω3, ω2, ω1)ω1
(ω1, ω3, ω2)ω2
(ω1, ω2, ω3)ω3

Whoever controls the agenda controls the outcome!

8. Majority Graphs & Tournaments

Definition

A majority graph is a directed graph built from voter preferences:

  • Vertices = candidates
  • Edge (i, j) exists if candidate i would beat j in a simple majority election

With an odd number of voters (no ties), the graph is:

  • Complete — every pair of candidates has an edge
  • Asymmetric — if (i,j) exists, (j,i) does not
  • Irreflexive — no self-edges

Such a graph is called a tournament.

Example: 3-candidate cycle
ω1 → ω2
ω2 → ω3
ω3 → ω1
(cycle ⇒ every candidate is a possible winner)

Possible Winners vs Condorcet Winners

Possible Winner

ωi is a possible winner if there exists some agenda that makes it win.

Test: Check if there is a path from ωi to every other ωj in the majority graph.

Computationally easy.

Condorcet Winner

ωi is a Condorcet winner if it wins for every possible agenda.

Test: Check if there is a direct edge from ωi to every other ωj.

Computationally easy. May not exist!

Exam Tip — Discussion Slide (23)

Given a majority graph, you may be asked to identify:

  • Possible winners: check reachability (path exists to all others)
  • Condorcet winners: check if one node has edges to ALL others (if the graph has a cycle, there is no Condorcet winner)

9. The Slater Ranking

Core Idea

The question "which social ranking should be selected?" becomes: find a ranking that is as consistent as possible with the majority graph.

Minimize the number of disagreements between the majority graph and the social choice.

Inconsistency Measure (Cost)

How to Calculate Cost

Given a ranking and a majority graph, count how many edges you'd need to flip (reverse) to make the graph consistent with the ranking.

Example (Slides 25-26)

Ranking: ω1 ≻* ω2 ≻* ω3 ≻* ω4

If the majority graph has edge (ω4, ω1) — i.e., ω4 beats ω1 — but our ranking puts ω1 above ω4, that's one inconsistency.

Flip that single edge → cost = 1


Alternate ranking: ω1 ≻* ω2 ≻* ω4 ≻* ω3

Need to flip (ω4, ω1) AND (ω3, ω4) → cost = 2

The Slater Ranking

The Slater ranking is the ordering with minimal cost (fewest edge flips needed).

Bad News
Computing the Slater ranking is NP-hard. Some methods reduce the search space by identifying similar candidates.

10. The Borda Count

Why Borda?
Plurality ignores most of a voter's preference order — it only looks at the top-ranked candidate. The Borda count takes the whole preference order into account.

How It Works

Point System

With k candidates:

  • 1st place gets k - 1 points
  • 2nd place gets k - 2 points
  • 3rd place gets k - 3 points
  • ... and so on until last place gets 0 points

Sum up points across all voters. The candidate with the highest total wins.

Worked Example (Slide 29)

3 voters, 3 candidates (so k=3: 1st=2pts, 2nd=1pt, 3rd=0pts)

Voter 1: ω2 ≻ ω1 ≻ ω3
Voter 2: ω3 ≻ ω2 ≻ ω1
Voter 3: ω1 ≻ ω2 ≻ ω3
CandidateVoter 1Voter 2Voter 3Total
ω11023
ω22114
ω30202

ω2 wins with Borda count of 4 (2 from 1st place + 1 + 1 from two 2nd places)

11. Alternative Vote (Instant Runoff Voting)

Key Features
  • Also known as Instant Runoff Voting (IRV)
  • Invented by William Robert Ware (1832-1915)
  • Social choice function — results in a single winner
  • Voters rank all candidates in order of preference
  • Counting happens in rounds — last place is eliminated each round
  • Eliminated candidate's votes are reallocated to their next choice
  • Continues until someone gets a majority (>50%)
  • Offers a solution to Condorcet's paradox

12. Desirable Properties of Voting Procedures

Can we classify what makes a "good" voting procedure? Three key properties + one anti-property:

1. The Pareto Property

If every voter prefers ωi over ωj, then ωi must be ranked over ωj in the social outcome.

Satisfied by: plurality, Borda. NOT by: sequential majority.

2. The Condorcet Winner Condition

If a Condorcet winner exists (beats every other candidate head-to-head), it must be ranked first.

Satisfied by: sequential majority. NOT by: plurality, Borda.

3. Independence of Irrelevant Alternatives (IIA)

Whether ωi is ranked above ωj in the social outcome should depend only on the relative orderings of ωi and ωj in voters' profiles — not on how other candidates are ranked.

NOT satisfied by: plurality, Borda, or sequential majority.

IIA Violation Example (Slides 37-38)

With plurality voting:

BeforeAfter
Group A8 voters: ω1 ≻ ω2 ≻ ω38 voters: ω1 ≻ ω2 ≻ ω3
Group B6 voters: ω2 ≻ ω3 ≻ ω19 voters: ω2 ≻ ω3 ≻ ω1
Group C5 voters: ω3 ≻ ω2 ≻ ω12 voters: ω3 ≻ ω2 ≻ ω1

Before: ω1 wins (8 > 6 > 5). After: ω2 wins (9 > 8 > 2).

But the relative ordering of ω1 vs ω2 didn't change for any voter! Only ω3's support shifted. IIA violated.

4. No Dictatorship

A social welfare function f is a dictatorship if for some agent i:

f(ω̅1, ω̅2, ... ω̅n) = ω̅i

The output is exactly the preference order of a single "dictator" agent. Plurality and Borda are NOT dictatorships — but dictatorships do satisfy Pareto and IIA!

13. Arrow's Impossibility Theorem

Arrow's Theorem

For preference aggregation problems with more than 2 candidates, the only social welfare function satisfying both the Pareto condition and IIA is a dictatorship.

This is a negative result: there are fundamental limits to designing perfectly fair aggregation mechanisms. No voting system can simultaneously be non-dictatorial, satisfy Pareto, and satisfy IIA.

Exam Key Point
Arrow's theorem applies to social welfare functions (rankings). It says mathematical perfection in voting is literally impossible when you have >2 candidates.

14. Gibbard-Satterthwaite Theorem

The Question
Voters can benefit by strategically misrepresenting their preferences (tactical voting / lying). Is there a social choice function where agents can never benefit from lying?
Gibbard-Satterthwaite Theorem

The only non-manipulable social choice function satisfying the Pareto property for elections with more than 2 candidates is a dictatorship.

Strategic manipulation is unavoidable for any non-dictatorial social choice function.

Silver Lining — Computational Complexity

Gibbard-Satterthwaite only says manipulation is possible in principle. It doesn't say HOW to misrepresent preferences.

Bartholdi, Tovey, and Trick showed: there are elections that are prone to manipulation in principle, but where manipulation is computationally complex.

"Single Transferable Vote" is NP-hard to manipulate!

So we can make it practically impossible to game the system, even though it's theoretically possible.

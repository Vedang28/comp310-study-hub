The Multi-Agent Environment
Slides 2–3 • 🎬 1:02

What is a Multi-Agent System?

A multi-agent system contains a number of agents that:

  • Interact through communication
  • Are able to act in an environment
  • Have different "spheres of influence" (which may overlap)
  • Will be linked by other organisational relationships

Key Assumption: Self-Interest

For this chapter, agents are assumed to be entirely self-interested — they have their own preferences over how the environment should be, and they want to maximise their own utility. This is the foundation of the game-theoretic analysis that follows.

The Core Challenge

In a multi-agent system, the outcome depends on the combination of actions chosen by all agents. No single agent fully controls the result. This chapter looks at how agents decide to interact in competitive situations — using game theory as the analytical framework.

Utilities & Preferences
Slides 4–5 • 🎬 1:02

Setting Up the Framework

  • Two agents: Ag = {i, j}
  • Set of possible outcomes: Ω = {ω1, ω2, ...}
  • Each agent has a utility function mapping outcomes to real numbers
ui : Ω → ℝ     uj : Ω → ℝ
Each agent assigns a real-valued utility to every possible outcome

Preference Orderings

Utility functions create preference orderings over outcomes:

  • ω ≥i ω' means ui(ω) ≥ ui(ω') — agent i weakly prefers ω
  • ω >i ω' means ui(ω) > ui(ω') — agent i strictly prefers ω

Utility is NOT money. It's just a way to encode preferences numerically. The utility curve is typically S-shaped (sigmoid) — diminishing returns at extremes.

Dominant Strategies
Slides 11–13 • 🎬 2:30

Dominant Strategy Definition

A strategy si is dominant for agent i if, no matter what strategy agent j chooses, agent i will do at least as well playing si as it would doing anything else.

How to Find Dominant Strategies

  1. For agent i: compare payoffs column-by-column. If one action gives a higher (or equal) payoff in every column, it dominates.
  2. For agent j: compare payoffs row-by-row. If one action gives a higher (or equal) payoff in every row, it dominates.
  3. A dominated strategy is one that is inferior — a rational agent will never play it.

There isn't always a unique un-dominated strategy! Some games have no dominant strategy for either player. Dominant strategy elimination is a first pass — if it works, great. If not, move to Nash equilibrium analysis.

Nash Equilibrium
Slides 14–18 • 🎬 2:30

Nash Equilibrium (NE) Definition

Two strategies s1 and s2 are in Nash Equilibrium if:

  • Under the assumption that i plays s1, agent j can do no better than play s2
  • Under the assumption that j plays s2, agent i can do no better than play s1

Neither agent has any incentive to unilaterally deviate from a Nash Equilibrium.

The "Cycle and Test" Method

To find all pure strategy NE in a 2×2 game:

  1. Cycle through every outcome (D,D), (D,C), (C,D), (C,C)
  2. For each outcome, test: can either agent improve their payoff by unilaterally switching?
  3. If neither can improve → it's a Nash Equilibrium

No pure strategy NE exists — every outcome has at least one agent wanting to switch. The agents are locked in an endless cycle of hunting for advantage.

Mixed Strategy

A mixed strategy introduces randomness: play action αk with probability pk, where p1 + p2 + ... + pk = 1. In matching pennies, playing heads and tails each with probability 0.5 is a mixed strategy NE — neither agent can do better by changing.

Nash's Theorem: Every finite game has a Nash equilibrium in mixed strategies. (Unlike pure strategies, which may not exist.) However, there may still be more than one NE.

Rock/Paper/Scissors

No pure strategy NE. The mixed strategy NE is to choose rock, paper, and scissors each with probability 1/3.

Pareto Optimality
Slide 25 • 🎬 4:02

Pareto Optimal (Pareto Efficient)

An outcome is Pareto optimal if there is no other outcome that makes one agent better off without making another agent worse off.

Key Properties

  • If an outcome is Pareto optimal: at least one agent would be reluctant to move away (they'd be worse off)
  • If an outcome is not Pareto optimal: there exists another outcome ω' that makes everyone at least as happy, if not happier — "reasonable" agents would agree to move
  • Think of it as: "no improvement without harm"

How to Find Pareto Optimal Outcomes

For each outcome ω, check: is there any other outcome ω' where every agent gets at least as much utility AND at least one agent gets strictly more? If yes → ω is NOT Pareto optimal. If no such ω' exists → ω IS Pareto optimal.

Pareto optimality is about all agents together, not individual rationality. An outcome can be both a Nash equilibrium and NOT Pareto optimal (this is the tragedy of the Prisoner's Dilemma). Compare every pair of outcomes systematically.

Social Welfare
Slides 26–27 • 🎬 5:22
SW(ω) = ∑i ∈ Ag ui(ω)
Social welfare = sum of all agents' utilities for outcome ω

Properties of Social Welfare

  • Think of it as the "total amount of money in the system"
  • Appropriate when the system has a single owner who cares about overall output
  • Does NOT consider distribution — a very skewed outcome (100, 0) can maximise social welfare
  • The SW-maximising outcome may differ from both the NE and the Pareto optimal outcomes

Competitive & Zero-Sum Interactions

TypeDefinitionImplication
Strictly competitivePreferences are diametrically opposedMy gain is your loss
Zero-sumui(ω) + uj(ω) = 0 for all ωFor me to get positive utility, you must get negative

Zero-sum encounters are very rare in real life, but people often act as if situations are zero-sum. Most games have room for mutually beneficial outcomes.

The Prisoner's Dilemma

The Setup

The Paradox: Individual rationality (defect) leads to mutual punishment (2,2) — which is the only non-Pareto-optimal outcome! Both would be better off cooperating (3,3), but self-interest prevents it. This is the fundamental problem of multi-agent interactions.

"The other prisoner is my twin"Both will think alike and choose to cooperateEven knowing the other will cooperate, you're still better off defecting
Program equilibriaSubmit conditional programs to a mediator: "cooperate if he will"Requires a trusted mediator mechanism
Shadow of the futureRepeat the game — future punishment deters defectionOnly works if future interactions are expected

The Iterated Prisoner's Dilemma (IPD)

Play the game more than once. If you expect to meet your opponent again, the incentive to defect evaporates because:

  • If you defect, you can be punished in future rounds
  • If you get suckered, the loss is amortised over remaining iterations

Cooperation is provably rational in the infinitely repeated PD.

Backwards Induction Problem: If both players know the game lasts exactly n rounds, round n-1 becomes the "last real round" → incentive to defect. This cascades backwards: in a finite, known-length PD, defection is always rational. But in practice, as long as there's some probability of repeating, cooperation can be better.

Axelrod's Tournament (1984)

Robert Axelrod invited researchers to submit programs for the iterated PD. Each program played every other program for 5 games of 200 rounds. The winner was the program with the best overall score.

Strategies in the Tournament

StrategyRule
ALL-DAlways defect — "the hawk strategy"
Tit-For-Tat (TFT)Round 0: cooperate. Round u>0: do what opponent did on round u-1
JOSSLike TFT, except periodically defect
TesterRound 1: defect. If opponent retaliates → play TFT. Otherwise intersperse cooperation & defection

TIT-FOR-TAT won the tournament — the simplest strategy entered! It succeeded because there were enough cooperative players to cooperate with. But note: the best approach depends on the full set of opponents.

Axelrod's Recipes for Success

  1. Don't be envious — don't treat it as zero-sum
  2. Don't be the first to defect — be nice, start by cooperating
  3. Retaliate appropriately — punish defection immediately, but use measured force
  4. Don't hold grudges — always reciprocate cooperation immediately
  5. Don't be too clever — TFT was the simplest program in the competition

Know the TFT strategy definition precisely (it's two lines). Know Axelrod's recipes. A common exam question asks you to simulate rounds of TFT vs ALL-D or TFT vs Tester.

Quick Decision Flowchart

1. Read the payoff matrix
   ↓
2. Check for dominant strategies
   → If found: that's the rational choice
   → If not: proceed to NE analysis
   ↓
3. Find all pure strategy NE (cycle & test)
   → If none exist: consider mixed strategies
   ↓
4. Check Pareto optimality for each outcome
   → Compare every pair: can we make someone
      better off without hurting anyone?
   ↓
5. Calculate social welfare for each outcome
   → Sum both agents' utilities
   → Highest sum = max social welfare
   ↓
6. Compare results — note any paradoxes!
   (NE ≠ Pareto optimal? That's the PD paradox)

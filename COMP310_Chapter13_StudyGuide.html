COMP310 Multi-Agent Systems — Shufang Zhu, University of Liverpool
Coalitional Games, The Core, Shapley Value & Modular Representations

1. Coalitional Games — Overview

What Are They?

Coalitional games model scenarios where agents can benefit by cooperating. The core question: given self-interested agents, when and how should they form teams?

Unlike the competitive games of Chapter 11, here agents ask: "Which coalition should I join?"

2. Three Stages of Cooperative Action

Sandholm et al. (1999) identified three stages:

1
Coalitional Structure Generation — Deciding in principle who will work together. Asks "which coalition should I join?" The result partitions agents into disjoint coalitions (a coalition structure).
2
Solving the Optimisation Problem — Deciding how to work together, solving the "joint problem" of the coalition. Finding how to maximise the coalition's utility (joint planning etc.).
3
Dividing the Benefits — Deciding "who gets what" in the payoff. Members can't ignore each other's preferences because members can defect: "if you try to give me a bad payoff, I can always walk away." Must consider fairness.

3. Formal Definition

Coalitional Game (Characteristic Function Game)
G = < Ag, ν >
  • Ag = {1, ..., n} — a set of agents
  • ν : 2Ag → R — the characteristic function of the game
Key Terms
  • Coalition: any subset C ⊆ Ag
  • Singleton Coalition: C contains a single member
  • Grand Coalition: C = Ag (all agents together)
  • ν(C) = k means coalition C will get payoff k if they cooperate

Grand coalition gives 25, but singletons sum to only 15. Cooperation pays off!

4. Superadditive vs Subadditive Games

Superadditive
ν(U) + ν(V) ≤ ν(U ∪ V)

Merging coalitions is always at least as good as staying apart.

Best coalition = Grand Coalition

Subadditive
ν(U) + ν(V) > ν(U ∪ V)

Merging coalitions loses value.

Best coalitions = Singletons

Warning
Some games are neither superadditive nor subadditive. In that case, the characteristic function must be evaluated for every possible coalition — this is exponentially complex.

5. Which Coalition Should I Join?

The Logic
  • Each coalition has a different characteristic function value
  • Agents prefer coalitions that are as productive as possible
  • A coalition will only form if all members prefer to be in it (i.e., they don't defect to a more preferable one)
Key Reduction

"Which coalition should I join?" reduces to "Which coalitions are stable?"

  • Is it rational for all members to stay, or could they benefit by defecting?
  • Stability is necessary but not sufficient for coalitions to form
  • Unstable coalitions will never form, but stable ones aren't guaranteed to form either

6. The Core

Definition

The core of a coalitional game is the set of feasible distributions of payoff to members of a coalition that no sub-coalition can reasonably object to.

"Is the grand coalition stable?" reduces to "Is the core non-empty?"

Formal Details

Outcomes & Objections

An outcome x for coalition C is a distribution x = <x1, ..., xk> that is:

  • Feasible: C can actually obtain the payoff
  • Efficient: all payoff is allocated: ν(C) = ∑ xi

Coalition C objects to outcome x for the grand coalition if there exists some outcome x' for C such that x'i > xi for ALL i ∈ C.

The core = set of outcomes for the grand coalition to which no coalition objects.

Example: v({1}) = 5, v({2}) = 5, v({1,2}) = 20

Possible outcomes: <20,0>, <19,1>, <18,2>, ..., <0,20>

  • <20, 0> is NOT in the core — agent 2 objects (can earn 5 alone, getting 0 here)
  • <14, 6> IS in the core — agent 2 gets 6 > 5 (more than solo), no objection
  • Core = all <x1, x2> where x1 ≥ 5, x2 ≥ 5, and x1 + x2 = 20

7. The Core and Fairness

The Fairness Problem

The core tells us which distributions are stable (no one wants to leave), but it doesn't tell us which distribution is fair.

Example: <14, 6> is in the core (both get more than solo), but is it fair that agent 1 gets 14 and agent 2 only gets 6 when both contribute equally as singletons?

This motivates the Shapley Value — a mathematical definition of fair division.

8. The Shapley Value — Introduction

What Is It?

The Shapley value is the best-known method for dividing benefits of cooperation fairly.

  • It takes into account how much an agent contributes
  • The Shapley value of agent i is the average amount that i is expected to contribute to a coalition
  • Based on marginal contribution across all permutations

9. Marginal Contribution

Definition

The marginal contribution of agent i to coalition C:

δi(C) = ν(C ∪ {i}) - ν(C)

δi(C) = the amount of value that agent i adds by joining coalition C.

If δi(C) = ν({i}), then there is no added value from i joining C (i adds only what it could earn alone).

Why Simple Average Is Wrong (Slide 21)

You might think Shapley value = average marginal contribution over all subsets:

φi = (1/2n-1) ∑ δi(C)

This is WRONG! The marginal contribution depends on the order in which agents join. An agent may contribute more if it joins first vs last.

10. The Three Axioms in Detail

Symmetry (Slide 18)

Agents that make the same contribution should get the same payoff.

Agents i and j are interchangeable if δi(C) = δj(C) for every C ⊆ Ag \ {i,j}.

If i and j are interchangeable, then φi = φj.

Dummy Player (Slide 19)

Agents with no synergy should only get what they earn solo.

Agent i is a dummy player if δi(C) = ν({i}) for every C ⊆ Ag \ {i}.

If i is a dummy player, then φi = ν({i}).

Additivity (Slide 20)

If two games are combined, the value an agent gets should be the sum of the values in the individual games.

Let G1 = <Ag, ν1> and G2 = <Ag, ν2>. Let G1+2 have ν1+2(C) = ν1(C) + ν2(C).

Then: φi1+2 = φi1 + φi2

11. The Shapley Value Formula

The Correct Formula (Slide 23)

Let Ci(o) = the set of agents that appear before agent i in ordering o.

φi = (1 / |Ag|!) ∑o ∈ Π(Ag) δi(Ci(o))

We consider the average marginal contribution an agent adds over all possible positions it could enter the coalition.

Example: o = (3, 1, 2)

C3(o) = ∅ (3 is first, nobody before it)

C1(o) = {3} (3 appears before 1)

C2(o) = {1, 3} (both 1 and 3 appear before 2)

12. Shapley Value — Worked Example

Full Calculation (Slide 24)

Ag = {1, 2}, with: ν({1}) = 5, ν({2}) = 10, ν({1,2}) = 20

Step 1: Calculate all marginal contributions

ExpressionCalculationResult
δ1(∅)ν(∅ ∪ {1}) - ν(∅) = 5 - 05
δ1({2})ν({2} ∪ {1}) - ν({2}) = 20 - 1010
δ2(∅)ν(∅ ∪ {2}) - ν(∅) = 10 - 010
δ2({1})ν({1} ∪ {2}) - ν({1}) = 20 - 515

Step 2: Calculate Shapley values

φ1 = (δ1(∅) + δ1({2})) / |Ag|! = (5 + 10) / 2 = 7.5
φ2 = (δ2(∅) + δ2({1})) / |Ag|! = (10 + 15) / 2 = 12.5

Agent 2 gets more (12.5 vs 7.5) because it contributes more on average. Total: 7.5 + 12.5 = 20 = ν({1,2}). The full payoff is distributed.

Exam Tip
For the exam, follow this exact procedure: (1) list all orderings, (2) for each ordering find what each agent adds when they join, (3) average across all orderings. For 3 agents there are 3! = 6 orderings.

13. The Representation Problem

Exponential Blow-Up

A naive representation of a coalitional game is exponential in the number of agents.

  • An n-player game has 2n - 1 coalitions
  • 100 players → 1.2 × 1030 lines in the characteristic function!
  • This is utterly infeasible in practice
Two Approaches
  • Complete but sometimes succinct: find a representation that captures everything, but is compact in most cases
  • Always succinct but not complete: always compact, but can't represent every possible game

Two modular representations: Induced Subgraphs and Marginal Contribution Nets

14. Induced Subgraphs

How It Works

Represent ν as an undirected weighted graph on Ag:

  • Each pair of agents (i, j) has a weight wi,j
  • Value of coalition C = sum of weights of edges within C:
ν(C) = ∑{i,j} ⊆ C wi,j
Graph Example (Slide 27)

Agents: A, B, C, D with edges: A-B=3, A-C=2, B-D=1, C-D=4, D-D(self)=5

  • ν({A,B,C}) = 3 + 2 = 5
  • ν({B,D}) = 1 + 5 = 6
  • ν({D}) = 5

Shapley Value for Induced Subgraphs

Elegant Shortcut (Slide 28-29)

Shapley value for an agent = half the income from the edges it's attached to:

φi = (1/2) ∑j ≠ i wi,j

This works because:

  • Each edge is a 2-player component game
  • Symmetry axiom: both agents in an edge are interchangeable → equal share
  • Additivity axiom: sum Shapley values across all edge-games

Computable in polynomial time!

Worked Example (Slide 29): A-B=3, A-C=2

ν({A,B,C}) = 3 + 2 = 5

AgentCalculationφ
A(3 + 2) / 22.5
B3 / 21.5
C2 / 21.0

Total: 2.5 + 1.5 + 1.0 = 5.0 = ν({A,B,C})

Limitations (Slide 30)
  • Representation is succinct but not complete — some characteristic functions can't be captured
  • Determining emptiness of the core is NP-complete
  • Checking if a specific distribution is in the core is co-NP-complete

15. Marginal Contribution Nets

How It Works

Represent ν as a set of rules: pattern → value

  • Pattern = conjunction of agents (with optional negations)
  • A rule applies to coalition C if C is a superset of the agents in the pattern
  • Value of C = sum of values of all rules that apply

Shapley Value for MC-Nets (Slide 33)

Calculation Method

For a rule with l agents on the LHS and value x:

φirule = x / l

(Each agent in the rule gets an equal share — symmetry axiom)

Then sum across all rules where agent i appears (additivity axiom):

φi = ∑r: i occurs in LHS of r φir

Advantage
MC-Nets are a complete representation — any characteristic function can be captured.
Disadvantage
In the worst case, may need exponentially many rules. Handling negative values requires a different method.

16. Coalition Structure Generation

The Problem

Sometimes we want to maximise social welfare — find the partition of agents into coalitions that maximises the sum of coalition values.

V(CS) = ∑C ∈ CS ν(C)
CS* = arg maxCS V(CS)
Example: Ag = {1, 2, 3}

7 possible coalitions, 5 possible coalition structures:

{{1},{2},{3}}, {{1},{2,3}}, {{2},{1,3}}, {{3},{1,2}}, {{1,2,3}}

Complexity

Exponentially many coalition structures in the number of agents.

Sandholm et al. [1999] developed a technique to find a coalition structure within some provable bound from the optimal one.

Next up, section 5, The Three Shapley Axioms, Rules of Fairness. To guarantee that this Shapley Value is universally mathematically fair, it leans on three unshakable axioms. Finally, Section 6, Subgraphs and Contribution Nets, Computing Fairness. Let's look at how AI systems actually crunch these Shapley Values in practice across massive networks. There are certain characteristic functions, certain highly complex games, that simply cannot be captured by this graph representation.

[7:25] Marginal Contribution Nets — complete representation

And that is exactly why AI systems also rely on Marginal Contribution Nets. Unlike subgraphs, Marginal Contribution Nets provide a totally complete representation of any characteristic function. Calculating within these Marginal Contribution Nets basically means putting those axioms we just talked about to work. And then, you just sum over all the rules to get the overall, perfectly fair Shapley Value for every single agent.
